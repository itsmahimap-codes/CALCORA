# 🧮 CALCORA

### Calculate. Understand. Simplify.

CALCORA is a modern, interactive smart calculator web application designed to go beyond basic arithmetic.

It combines everyday calculations, scientific functions, financial tools, student utilities, natural-language calculations, calculation history, and smart step-by-step explanations in a clean and responsive interface.

---

## ✨ Features

### 🧮 Basic Calculator
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal calculations
- Delete and clear functions
- Division-by-zero protection

### 🧪 Scientific Calculator
- Square root
- Square
- Cube
- Sine
- Cosine
- Tangent
- Logarithm
- Natural logarithm
- π (Pi)

### 🧠 Smart Explain
CALCORA explains calculations in a simple step-by-step format instead of displaying only the final answer.

Example:

20 × 5

Multiplication

Multiply 20 by 5.

20 × 5 = 100

Answer: 100
